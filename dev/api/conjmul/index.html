Conjugated moment multiplication

The conjmul! methods over MultilevelKernelInterpolation's moment types: the conjugating counterpart to the mul! methods on the previous page, used by the adjoint orientation.

GENERATED by H2Factory's moment macros, so Documenter records their source inside H2Factory rather than under MultilevelKernelInterpolation's src/. They are selected by binding, not by source path; see docs/make.jl.

H2Factory.Interfaces.conjmul! — Method
conjmul!(result, momentcollection::MultilevelKernelInterpolation.TrialMomentCollection, moment::PolynomialMoment, α::AbstractVector, β::Number)

Apply one coefficient from α to each moment component, add β * result, and store the conjugated product in result.

source
H2Factory.Interfaces.conjmul! — Method
conjmul!(moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}, momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * conj(y), for i in 1:D

Arguments

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: A moment.
  • momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MultilevelKernelInterpolation.ToeplitzPolynomialMoment{2,ComplexF64}((10,))
mcol = MultilevelKernelInterpolation.TestMomentCollection{2,ComplexF64}((10, 10))
y = Array(1:10) * im

H2Factory.conjmul!(m, mcol, y)

Returns

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: The updated moment after conjugate multiplication.
source
H2Factory.Interfaces.conjmul! — Method
conjmul!(moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}, momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the conjugated factors of the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

Arguments

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: A moment.
  • momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MultilevelKernelInterpolation.ToeplitzPolynomialMoment{2,ComplexF64}((3, 3))
mcol = MultilevelKernelInterpolation.TestMomentCollection{2,ComplexF64}((9, 9))
y = Array(1:9) * im

H2Factory.conjmul!(m, mcol, y, 1.0, 2.0)

Returns

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: The updated moment after conjugate multiplication.
