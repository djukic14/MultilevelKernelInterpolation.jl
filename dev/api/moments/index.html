Moments

Moment types, the collections that map DOF amplitudes to and from them, and the assemblers that populate them from a BEAST space.

The generated mul! and conjmul! methods over these types are on their own pages, since their rendered signatures are long enough to dominate any page they share.

MultilevelKernelInterpolation.AbstractBsplineDenseMoment — Type
abstract type AbstractBsplineDenseMoment{D,T} <: H2Factory.AbstractToeplitzMoment{D,T}

Moment with raw B-spline arrays and reduced-basis scratch arrays. I2I/O2O and moment assembly use the raw basis; dense I2O uses the reduced basis. BsplineDenseModulation converts between them.

Inherits AbstractToeplitzMoment to reuse its two-array pool allocator, not its FFTs. The modulation policy, rather than this supertype, selects the conversion.

MultilevelKernelInterpolation.PolynomialMoment — Type
struct MultilevelKernelInterpolation.PolynomialMoment{D,T} <: H2Factory.AbstractMoment{D,T}

The MultilevelKernelInterpolation.PolynomialMoment struct represents a moment consisting of D arrays of type T. This struct was created with the @createmoment macro of H2Factory.jl.

Fields

  • moments::SVector{D,T}: D arrays of type T.

Constructors

  • MultilevelKernelInterpolation.PolynomialMoment{D,T}(size::NTuple{N,I}) where {D,T,I,N}: Creates a new moment with D arrays of type T and size size.
  • MultilevelKernelInterpolation.PolynomialMoment{D,T}(moments::SVector{D,T}) where {D,T}: Creates a new moment with the given moments in an SVector.
  • MultilevelKernelInterpolation.PolynomialMoment{D}(moments::SVector{D,T}) where {D,T}: Creates a new moment with the given moments in an SVector, inferring D from the input.
  • MultilevelKernelInterpolation.PolynomialMoment(moments::SVector{D,T}) where {D,T}: Creates a new moment with the given moments in an SVector, inferring T and D from the input.
  • MultilevelKernelInterpolation.PolynomialMoment{D,T}(m::MultilevelKernelInterpolation.PolynomialMoment{D,T}) where {D,T}: Creates a new moment of the same type as m, with arrays of the same size as the first array of m. The fields of m are not copied.
  • MultilevelKernelInterpolation.PolynomialMoment{D}(m::MultilevelKernelInterpolation.PolynomialMoment{D,T}) where {D,T}: Creates a new moment of the same type as m, with arrays of the same size as the first array of m, inferring T from the input. The fields of m are not copied.
  • MultilevelKernelInterpolation.PolynomialMoment(m::MultilevelKernelInterpolation.PolynomialMoment{D,T}) where {D,T}: Creates a new moment of the same type as m, with arrays of the same size as the first array of m, inferring T and D from the input.

Example

m = MultilevelKernelInterpolation.PolynomialMoment{2,Float64}((3, 3))

# access the first array of the moment
m[1] == m.moments[1]

# create a new moment of the same type as `m` without copying the fields of `m`
m2 = MultilevelKernelInterpolation.PolynomialMoment(m)

typeof(m2) == typeof(m)
