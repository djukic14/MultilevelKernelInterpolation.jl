Moment multiplication

The mul! methods over MultilevelKernelInterpolation's moment types, carrying DOF amplitudes into a moment and back out.

GENERATED by H2Factory's moment macros, so Documenter records their source inside H2Factory rather than under MultilevelKernelInterpolation's src/. They are selected by binding, not by source path; see docs/make.jl.

LinearAlgebra.mul! — Method
LinearAlgebra.mul!(moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}, momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}, y::AbstractArray{<:Number})

Calculate the superposition of the moments inside momentcollection according to the array y. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = momentcollection[i] * y, for i in 1:D

Arguments

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: A moment.
  • momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}: A momentcollection.
  • y::AbstractArray{<:Number}: An abstract array of numbers.

Example

m = MultilevelKernelInterpolation.ToeplitzPolynomialMoment{2,Float64}((10,))
mcol = MultilevelKernelInterpolation.TestMomentCollection{2,Float64}((10, 10))
y = zeros(Float64, 10)

LinearAlgebra.mul!(m, mcol, y)

Returns

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: The updated moment after multiplication.
source
LinearAlgebra.mul! — Method
LinearAlgebra.mul!(moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}, momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}, y::AbstractArray{<:Number}, α::Number, β::Number)

Calculate the superposition of the moments inside momentcollection according to the array y and the factors α and β. The result is stored in moment. If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

moment[i] = α * momentcollection[i] * conj(y) + β * moment[i], for i in 1:D

Arguments

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: A moment.
  • momentcollection::MultilevelKernelInterpolation.TestMomentCollection{D,T2}: A momentcollection.

Example

m = MultilevelKernelInterpolation.ToeplitzPolynomialMoment{2,Float64}((3, 3))
mcol = MultilevelKernelInterpolation.TestMomentCollection{2,Float64}((9, 9))
y = ones(Float64, 9)

LinearAlgebra.mul!(m, mcol, y, 1.0, 2.0)

Returns

  • moment::MultilevelKernelInterpolation.ToeplitzPolynomialMoment{D,T1}: The updated moment.

LinearAlgebra.mul! — Method
LinearAlgebra.mul!(result::AbstractArray{<:Number}, momentcollection::MultilevelKernelInterpolation.TrialMomentCollection{D,T2}, moment::PolynomialMoment{D,T1}, α::Number, β::Number)

Transpose operation to LinearAlgebra.mul!(moment, momentcollection, result, α, β). If the arrays of moment are interpreted as a vector, the operation is equivalent to the matrix-vector product

result *= α
result += β * transpose(momentcollection[i]) * moment[i], for i in 1:D

Arguments

  • result::AbstractArray{<:Number}: An abstract array of numbers.
  • moment::PolynomialMoment{D,T1}: A moment.
  • momentcollection::MultilevelKernelInterpolation.TrialMomentCollection{D,T2}: A momentcollection.

Example

m = PolynomialMoment{2,ComplexF64}((3, 3))
mcol = MultilevelKernelInterpolation.TrialMomentCollection{2,ComplexF64}((9, 9))
y = Array(1:9) * im

LinearAlgebra.mul!(y, mcol, m, 1.0, 2.0)

Returns

  • result::AbstractArray{<:Number}: Updated array after the multiplication.
