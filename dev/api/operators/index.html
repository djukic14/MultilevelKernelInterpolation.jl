MultilevelKernelInterpolation.HyperSingularMoment — Type
struct HyperSingularMoment

Concatenate the three normal moments and three surface-curl moments of scalar j:

\[∫_Γ j(x) n(x) L_i(x) dx\]

and ∫_Γ (∇_x j(x) × n(x)) L_i(x) dx. The integrand reads the surface curl from BEAST's f.curl.

MultilevelKernelInterpolation.symmetrycomponentaction — Method
symmetrycomponentaction(i2otranslation)

Return the lattice-symmetry action on field components: nothing, VectorField(), TrueTensor(), or PseudoTensor() from H2Factory.

Container shape cannot choose this action: Hessian, dyadic, and curl kernels all use 3-by-3 blocks, but curl is a pseudo-tensor. For symmetry S:

true tensor:   G(Sx) = S G(x) Sᵀ
pseudo-tensor: K(Sx) = det(S) S K(x) Sᵀ

Scalar kernels need only the sample permutation, so return nothing.
