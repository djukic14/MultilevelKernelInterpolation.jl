Polynomials

The interpolation bases: equidistant and barycentric Lagrange, and the B-spline families including the buffered variants whose buffer is sized from the real protrusion.

MultilevelKernelInterpolation.BufferedBsplinePolynomialEquidistant — Type
BufferedBsplinePolynomialEquidistant{D,T,B}

Tensor-product B-spline basis with equidistant knots and extra knots beyond [0,1]. D is the spatial dimension, T the scalar type, and B the underlying 1-D basis type.

The requested buffer policy is stored as a field, not a type parameter: grids built with different policies can still be Toeplitz-compatible. Policy dispatch occurs only at construction, not during multiplication.

MultilevelKernelInterpolation.levelpolynomials — Method
levelpolynomials(poly, levels, cond; increase=MultilevelKernelInterpolation.increase)

Build one polynomial per level, returned in the order of levels. Work from fine to coarse: use increase when cond(level) is true, except on the first step, and noincrease otherwise. Both receive that level's protrusion. The initial basis uses the maximum protrusion across levels.

MultilevelKernelInterpolation.realizedprotrusion — Method
realizedprotrusion(polynomial)

Return how far the constructed sampling domain extends beyond [0,1]^D, relative to the box side length. This includes any rounding or inherited extension from increase/noincrease, unlike the geometric protrusion supplied before construction. The fallback is zero; buffered B-splines and scaled/shifted bases override it.

source
