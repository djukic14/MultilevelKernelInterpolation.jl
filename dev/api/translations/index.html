Translations

I2I, O2O and I2O translations, their collections, and the Toeplitz and B-spline accelerated routes.

MultilevelKernelInterpolation.BSPLINEREDUCTIONKRONECKERCROSSOVER — Constant
BSPLINEREDUCTIONKRONECKERCROSSOVER

Switch between combined and separable B-spline reduction at this per-axis reduced size. Below the threshold, use a precomputed Kronecker matrix on each side (O(n^(3D)) work). At or above it, apply one factor per axis (O(n^(2D+1))). The threshold matches interpolationinverse, though it controls a different cost there.

MultilevelKernelInterpolation.O2OTranslator — Type
struct O2OTranslator{T}

Read-only reference cache of transposed I2I matrices, indexed by level and sector. translationmatrices is a dictionary, or nothing when there are no transfers.

Construct with O2OTranslator(c::H2Factory.I2ITranslationCollection). The dense trait returns this type; the separable trait returns O2OTranslatorOneDim. Traversal does not use this cache: it applies transpose/adjoint transfers from the I2I collection. Workspace scratch also comes from that collection via H2Factory.o2ochannels.

MultilevelKernelInterpolation.O2OTranslatorOneDim — Type
struct O2OTranslatorOneDim{T}

Read-only O2O reference cache of transposed one-dimensional factors. Built by O2OTranslator for a SeparableI2I collection. Traversal instead applies transpose/adjoint to the original separable I2I transfer. No separate O2O strategy is needed; see I2ITranslatorOneDim.

H2Factory.Interfaces.applycouplingkernel! — Method
applycouplingkernel!(out, in, tfs::BsplineI2OTranslationCollection, ::BsplineI2OTranslationTrait,
                     receivingnode, translatingnode, direction, accumulation, context)

Apply the stored coupling to the reduced arrays of in and out. Modulation prepares these arrays; the generic dense kernel instead uses raw storage.

_bsplinei2oapply! handles a scalar matrix, independent component matrices, or a fully coupled matrix of matrices. Transpose/adjoint transform each block lazily and swap outer component indices where needed, without allocating a transformed container.

The guarded H2Factory.applycoupling! entry runs assertnosymmetry before this kernel.

MultilevelKernelInterpolation.I2ITranslatorOneDim — Method
I2ITranslatorOneDim(polynomials, levels)

Build a read-only H2Factory.I2ITranslationCollection with the SeparableI2I trait. polynomials and levels are matching sequences. Each transfer stores an NTuple{D} of one-dimensional factors, applied as an H2Factory.SeparableTransfer.

For N nodes per axis, storage is O(D*N^2) rather than the dense product's O(N^(2D)). Select this with TranslatorStrategy(; i2istrategy=OneDimI2IStrategy()). Allocate workspace scratch through H2Factory.i2ichannels and o2ochannels.

interpolationinverse(interpolationmatrix, bspline)

Build the inverse conversion for the reduced B-spline basis. Degree 1 returns I. Active knot removal composes the inverse with cheap averaging. Below the empirical order-7 crossover, store a combined Kronecker matrix; otherwise keep the 1-D factor for separable application.

function ndimi2itranslations(poly, parentpoly)

Return the tensor-product child-to-parent matrices, one per sector (2^D), where D = dims(poly).

Check the underlying 1-D matrices with testonedimensionali2i. B-spline knot insertion is exact even when basis orders differ. Lagrange interpolation is exact for a fixed order, but need not be when the order increases.

MultilevelKernelInterpolation.separable1dinterpolations! — Method
separable1dinterpolations!(res, inverse::SMatrix, a, buffers)
separable1dinterpolations!(res, inverse::Matrix, a, buffers)

Convert coefficient array a into the basis selected by inverse, writing to res. An SMatrix is a 1-D factor applied along each axis; a Matrix is the combined Kronecker product applied to the flattened array.

For the separable path, reuse the D-1 arrays from separablescratch. Axes run last-to-first. Intermediate k has shape from^(D-k) × to^k. The combined path ignores buffers. Omitting scratch allocates it for one-off use.

MultilevelKernelInterpolation.symmetryreduceddensei2ocoupling — Method
symmetryreduceddensei2ocoupling(operator, tree, polynomials, translatingplan; verbose=false)

Build dense couplings with one matrix per group of lattice directions related by symmetry. Other directions use grid permutations; reduction adds no approximation. In 3-D, permutations need O(b^3) entries versus O(b^6) for a dense matrix.

Supports Galerkin maps with non-B-spline polynomials and scalar or true/pseudo-tensor 3-by-3 kernels. Unsupported families error; non-lattice trees use unreduced couplings.

source
MultilevelKernelInterpolation.symmetryreducedtoeplitzi2ocoupling — Method
symmetryreducedtoeplitzi2ocoupling(operator, tree, treepolynomials, translatingplan; verbose=true)

Build Toeplitz couplings with one difference tensor per group of symmetry-related lattice directions. Other directions use index permutations, without extra approximation.

Equal spacing and extent on every tensor axis allow the full signed-permutation group (D! * 2^D elements, 48 in 3-D). symmetrycomponentaction selects the kernel's field-component transformation. Non-lattice displacements use unreduced couplings.

MultilevelKernelInterpolation.testonedimensionali2i — Method
testonedimensionali2i(poly, parentpoly, i2i0, i2i1; n=numpolynomials(poly)[1]*10, verbose=false)

Check a pair of 1-D child-to-parent transfer matrices by evaluating both bases directly. Sample each child interval at n points and compare the transferred values with the parent basis at tolerance 1e-10. Return true or false.

This checks onedimi2itranslations without moments, trees, or a mesh. Lagrange transfers with increasing order need not pass; see ndimi2itranslations.

MultilevelKernelInterpolation.toeplitzcompatible — Method
toeplitzcompatible(testpolynomial, trialpolynomial)

Check whether both polynomials use the same grid for Toeplitz coupling. Compare type, dimension, node counts, and node positions along every axis. If sampling matrices exist, both must have one and the matrices must agree.

Equal sizes alone do not establish equal spacing. Structural == is also insufficient: some polynomial types compare unequal even when their grids match.
